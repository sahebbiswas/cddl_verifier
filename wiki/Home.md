# CBOR-CDDL Analyzer (Wiki Home)

A Python tool for analyzing CBOR data against CDDL schemas and generating annotated EDN output.

- **Purpose:** Validate CBOR against CDDL and produce human-readable EDN annotated with CDDL field names.
- **Key features:** parse CDDL, parse CBOR, validate, generate annotated EDN.
